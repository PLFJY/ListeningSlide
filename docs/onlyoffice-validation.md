# 验证记录

默认及唯一放映路径为官方 ONLYOFFICE 10.0.0 x2t → PPTY → SDKJS。

## 无窗口检查

- `pnpm test`：55 项核心逻辑单元测试，覆盖裁剪边界、XML/关系读取、音频资源复用、手势、命中检测、归档安全、转换队列、原生批注适配和批注/导航隔离。批注测试使用内存中的 SDK 替身，覆盖坐标换算、荧光笔参数、异页/多指过滤、取消与清空时结束笔画，不启动窗口。新增用例覆盖书写模式禁止手势请求、切换前遗留滑动、异步导航/迟到回复失效，以及显式翻页按钮保持可用。按钮处理器另覆盖轻点、划动、划出再返回、电教设备零 detail 的合成点击和取消触摸后的键盘操作。
- `pnpm run build`：检查 TypeScript 并构建网页、Electron 主进程及 preload，启用 noUnusedLocals / noUnusedParameters。

浏览器和 Electron 窗口自动测试、相关依赖及 CI 步骤已删除。界面与放映交互交给人工测试。

## 2026-10-22 触屏专项检查

本次检查覆盖宿主 Pointer Events、批注消息桥、导航版本检查、菜单/总览滚动、音频命中、播放器拖动/缩放和全屏生命周期。新增测试仍为 Node 环境，不启动浏览器或 Electron 窗口。

- SDK 现有 `asc_putLinecap` / `asc_putLinejoin` 支持圆头和圆角，已在自有 `annotations.js` 设置；固定上游源码检出无修改。
- 舞台按区域设置 touch-action：课件及黑边接收书写/翻页，菜单、总览和播放器内容允许纵向滚动，拖动及缩放手柄保留独立指针捕获。
- 多接触点会使当前翻页手势失效，直到所有手指抬起；书写过程中额外接触不会操作工具或翻页。此逻辑不等于硬件级掌触识别。
- 失焦、隐藏、窗口尺寸变化、取消或丢失实际指针捕获时清理手势；忽略从子元素向舞台转移隐式捕获时产生的旧捕获丢失事件。
- 兼容点击按 pointerId 屏蔽，避免划动/书写结束后误点，也避免吞掉下一次正常点击或键盘操作。翻页按钮接受较慢的静止轻按。
- 使用合并的笔迹采样，单条消息最多 64 个点；小音频图标提供约 44 CSS px 的手指命中范围，保留精确命中优先。
- 播放器在缩小屏幕/退出全屏后限制宽高，预留底部展开和缩放区域；取消拖动不自动展开，抬手坐标同步提交；折叠拖动保留原展开尺寸。粗指针环境加大进度条滑块。
- 55 项测试包含接触点生命周期、兼容点击、合并采样、圆头参数、触摸命中、窗口尺寸约束、播放器事件处理器和按钮捕获丢失等回归检查。

真实 Windows 电教触屏、多指、掌触、压感笔以及硬件驱动产生的合成事件尚未实机验证。临时预览启动/可访问性接口未稳定返回应用窗口，未据此声称完成本次圆头显示或真实触屏交互验收。此前的人工记录仅适用于当时版本。

## 人工检查参考

运行 `pnpm run dev` 后，可检查：

- 主页右下角作者按钮、作者介绍和 ONLYOFFICE 许可，关闭及重新打开弹窗。作者内容在 `src/author.ts` 编辑，可留空或填写多行纯文本。
- 打开真实课件，检查排版、带进入动画的对象初始隐藏，以及点击、方向键、侧边按钮、手势和滚轮推进动画后再翻页。
- 连续滚轮可以完成当前动画，不额外跳过下一步；反向操作、全屏、关闭和重新打开课件正常。
- 音频图标、播放暂停、裁剪、进度、快退、倍速、A–B 循环及跨页固定正常。
- 左下角笔工具：鼠标、触屏和笔书写不触发滑动翻页或音频，画笔/荧光笔颜色与粗细、整笔擦除、本页清空、P / Esc、翻页后墨迹保留、重新打开后丢弃。
- 首页外观按钮、明暗主题、窄屏布局、总览与弹窗可读性，以及系统减少动态效果/透明度和增强对比度偏好。

## 平台边界

- 转换器为来源、版本、哈希可追溯的官方二进制，未完整编译所有 ONLYOFFICE C++ 组件。
- 缺失字体使用随包开放字体替代，复杂字体排版仍需目视检查。
- 已测 Windows 环境有 Microsoft VC++ v14 runtime；当前不附带微软 CRT，未验证缺少该运行库的干净系统。
- Windows x64 在 ARM64 上仿真通过不等于原生 ARM64 Electron 验证。UNC 共享目录启动曾出现 GPU 子进程失败，使用本地副本后通过。
